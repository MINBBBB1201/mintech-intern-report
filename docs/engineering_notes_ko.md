# 민테크 인턴십 엔지니어링 리포트

민테크에서 OLED 증착장비 제조 지원 업무에 참여했다. 인턴십 이후에는 준비 조건과 측정 기록을 연결하는 과제를 정했다. 캐리어와 witness coupon을 사례로 기록 항목을 정하고, 두 실행을 비교할 기준과 계산 도구를 만들었다. 이 문서는 그 설계의 세부 내용을 정리한다. 경험부터 결과까지 이어 읽을 때는 [통합 보고서](engineering_report_ko.md)를 사용한다.

인턴십이 끝난 뒤 작성한 보고서이며, 소프트웨어 검증일은 2026-10-24다. 문서 초안과 코드 구현에는 AI 도구를 사용했다.

## 1. 활동 범위와 시점

| 시점 | 수행 내용 |
|---|---|
| 근무 기간 | 1개월 |
| 근무 부서·직급 | 제조기술·인턴 |
| 공식 담당업무 | OLED 증착장비 제조 지원 |
| 인턴십 초반 | 공장 현장 업무 보조 |
| 인턴십 실무 참여 | 사수를 따라 실무에 참여하고 지시받은 제조 지원 업무 수행 |
| 인턴십 이후 | 캐리어·쿠폰 비교설계, 체크리스트, 기록 양식과 4M 분석 시제품 구현 |
| 2026-10-24 후속 검증 | 기록 검증 도구의 오류 주입 시험 55개 실행 |

인턴십 경험 설명에 따른 담당업무는 OLED 증착장비 제조 지원이다. 캐리어·쿠폰 비교설계와 4M 분석은 인턴십 이후 만든 포트폴리오 산출물이다.

## 2. 내가 맡은 부분과 도구의 역할

현장에서는 공장 업무를 보조하고 사수의 지시에 따라 제조 지원 업무를 수행했다. 인턴십 이후에는 당시 경험한 업무의 범위를 설명하고, 이를 엔지니어링과 AI에 연결하는 별도 보고서와 포트폴리오를 만들도록 목표와 요구를 제시했다.

후속 작업에는 AI 도구를 사용했다. 설계 문서와 코드, 분석 자료의 작성을 요청하고 참고 디자인을 제시했으며, 수정 과정에서는 기술 설명과 내 역할을 함께 보여 주도록 방향을 조정했다. 기술 설계의 초안, 코드 구현과 자동 검사는 AI 도구를 활용해 진행했다.

| 구분 | 담당한 내용 |
|---|---|
| 현장 역할 | 감독 아래 공장 업무 보조와 OLED 증착장비 제조 지원 |
| 후속 작업에서 내가 맡은 부분 | 경험 설명, 프로젝트 목표와 요구 제시, 보고서 구성 및 역할 설명의 수정 방향 제시 |
| AI 도구를 활용한 작업 | 기록 구조와 비교설계 초안, 문서 및 코드 구현, 시험 입력 구성과 자동 검사 |
| 결과물 | 기록 양식, 배치도, 체크리스트, 검증 코드와 별도 4M 분석 |

## 3. 포트폴리오 문제 정의

캐리어가 지정 위치에 완전히 안착했는지, 쿠폰 ID·좌표·방향이 맞는지, 측정점이 같은지를 기록하지 않으면 실행 간 두께 값을 직접 비교하기 어렵다. 준비 오류와 공정 또는 측정 변동이 한 결과에 섞일 수 있기 때문이다.

후속 설계에서는 접촉식 스토퍼와 비접촉 기록 방식을 비교했다. 접촉식 장치를 추가하려면 실제 치수와 접촉 허용 조건, 오염과 간섭을 확인해야 한다. 현재 정보로 구현할 수 있는 범위는 준비 정보를 연결하는 배치도와 체크리스트였다. 이 선택은 문서상 대안 검토다.

수정안은 비접촉 배치도와 체크리스트다. 다음 항목을 한 실행 ID로 연결했다.

- 캐리어 ID와 안착 확인점
- 쿠폰 ID, 좌표와 방향
- 고정 측정점 번호
- 준비 오류와 수정 이력
- A 또는 B 조건, 실제 실행 순서와 블록

## 4. 비교설계

A는 기존 준비 방식이고 B는 체크리스트 준비 방식이다. 가능한 범위에서 같은 쿠폰 규격, 측정 장비, 고정 측정점과 승인된 시험 조건을 사용한다. A와 B를 한 쌍으로 묶고 AB와 BA를 번갈아 배치한다.

| 분석 대상 | 판단 기준 |
|---|---|
| 준비 오류 | ID 불일치, 안착 확인 누락, 쿠폰 ID·좌표·방향 오류 |
| 고정점 두께 범위 | 실행별 고정 측정점의 최댓값과 최솟값 차이 |
| 순서 효과 | AB와 BA에서 차이의 방향이 같은지 확인 |
| 블록 효과 | 날짜, 작업 구간, 장비·챔버 상태에 따라 결과가 달라지는지 확인 |
| 측정 반복성 | 같은 대상과 측정점을 반복 측정한 차이 확인 |

측정 반복성이나 블록 차이가 A와 B의 차이와 비슷하면 준비 방식의 효과를 확정하지 않는다. 비교 절차는 [캐리어·쿠폰 체크리스트 비교설계](comparison_plan.md)에 정리했다.

## 5. 현재 산출물과 검증 상태

공개 가능한 현장 A/B 측정값은 포함하지 않았다. 따라서 체크리스트가 준비 오류를 줄였거나 두께 범위를 좁혔다고 결론 내리지 않는다. 비교 조건과 기록 항목, 계산식, 예시 및 후속 검증 기준을 정리했다. 실제 효과를 판정하려면 FIELD_MEASUREMENT 자료를 입력하고 측정 반복성과 블록 효과를 함께 분석해야 한다.

## 6. 기록 검증 도구의 실행 결과

2026-10-24에 구성한 시험 입력으로 기록 검증 도구를 실행했다. 정상 AB 및 BA, 25개 필수 필드의 개별 누락, 중복 ID, 잘못된 날짜와 수치, 조건 및 측정점 불일치, 자료 범주 혼입과 빈 입력을 포함한 55개 시험이 예상한 결과와 일치했다.

도구는 유효한 두 방법의 측정점 집합이 같을 때만 두께 범위를 계산한다. 같은 실행의 오류 건수를 측정점 수만큼 중복 집계하지 않고, 반복 측정은 검토 대상으로 남긴다. 이 결과는 기록 검사와 계산 동작을 확인한 SOFTWARE_TEST다. 현장 준비 오류나 박막 품질의 개선을 입증하지 않는다. 재현 방법과 원출력은 [기록 검증 결과](software_validation.md)에 정리했다.

## 7. 후속 AI 분석

인턴십 뒤에는 작업 조건을 사람, 설비, 자재와 방법의 4M 항목으로 표현하는 별도 분석 예제를 만들었다. 분석 시제품에서는 두 분류모델의 결함 탐지와 오경보를 비교했다. 이 구현은 현장에 배포한 시스템이 아니라 인턴 경험을 데이터 분석으로 확장한 후속 작업이다.
