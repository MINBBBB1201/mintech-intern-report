# 민테크 인턴십 포트폴리오 요약

민테크 제조기술 인턴으로 공장 업무를 보조하고 사수를 따라 OLED 증착장비 제조 지원 실무에 참여했다. 인턴십 이후에는 실행마다 무엇을 기록해야 결과를 비교할 수 있는지 살폈다. [통합 보고서](engineering_report_ko.md)는 경험, 설계 판단과 실행 결과를 순서대로 설명한다.

| 항목 | 내용 |
|---|---|
| 근무처 | 민테크 |
| 근무 기간 | 1개월 |

| 공식 담당업무 | OLED 증착장비 제조 지원 |

현장 역할은 본인의 인턴십 경험 설명에 따른다. 개인 증빙 원본은 이 저장소에 포함하지 않는다.

## 내가 맡은 부분과 후속 작업

인턴십에서는 공장 업무를 보조하고 사수의 지시에 따라 제조 지원 업무를 수행했다. 후속 작업에서는 이 경험을 엔지니어링과 AI에 연결한 보고서로 정리하도록 목표와 요구를 제시했다. 경험한 업무의 범위를 설명하고 참고 디자인을 제공했으며, 보고서의 구성과 역할 설명을 수정하도록 방향을 제시했다.

설계 문서와 코드, 시험 입력과 자동 검사에는 AI 도구를 사용했다. 그 결과 캐리어와 witness coupon의 식별 정보, 좌표, 방향과 고정 측정점을 같은 실행 ID로 연결하는 기록 구조와 비접촉 체크리스트를 구성했다. 비교설계는 A와 B의 실행 순서, 블록, 준비 오류, 두께 범위와 측정 반복성을 나눠 기록한다.

공개 가능한 현장 A/B 측정값은 포함하지 않았다. 현재 결과는 후속 기록 설계, 소프트웨어 시험과 별도 합성 데이터 분석이다.

## 현재 결과

기록 구조와 A/B 비교 기준을 정하고 계산 워크북과 분석 코드를 구성했다. 현장 기록 CSV와 워크북의 실측 영역은 비어 있고, 입력 예시는 실제 집계에서 분리돼 있다.

2026-10-24에는 기록 검증 도구에 정상 입력과 오류를 넣은 55개 시험을 실행했다. 필수값 누락, 중복 ID, 잘못된 수치, A/B 조건 및 측정점 불일치와 자료 범주 혼입을 포함하며 모든 시험에서 예상한 처리를 확인했다. 이는 현장 오류 감소율이 아니라 소프트웨어 검증 결과다.

4M 분석은 코드가 생성한 4,000행 데이터로 LogisticRegression과 LightGBM의 결함 탐지와 오경보를 비교한다. 이 결과는 회사 생산 데이터의 성능이 아니라 분석 파이프라인의 동작을 보여 준다.

## 다음 검증

1. 공개 가능한 FIELD_MEASUREMENT 자료를 확보한다.
2. 측정 반복성을 먼저 확인한다.
3. AB·BA 실행 순서와 시간 블록을 균형 있게 구성한다.
4. 준비 오류와 고정점 두께 범위를 함께 분석한다.
5. 담당 엔지니어가 안전·오염 조건과 현장 적용 가능성을 검토한다.

## 제출 범위

제출할 때는 이 요약과 위의 공개 산출물, `code/`, `outputs/`만 포함한다. `_internal/`은 조사 과정과 창작 초안을 보관한 작업 폴더이므로 제출하지 않는다. 사업자등록증과 인턴 근무확인서는 원본을 공개 폴더에 넣지 않고, 요청받았을 때 개인 정보·사업자번호·서명·직인을 가린 사본으로 제출한다.
