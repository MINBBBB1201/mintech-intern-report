# 캐리어·쿠폰 준비 체크리스트

인턴십 이후 캐리어 안착, witness coupon 배치와 측정값을 같은 실행 ID로 기록하도록 절차를 설계했다. 현장 사용 전에는 최신 도면, 승인된 절차와 담당자의 검토가 필요하다.

## 1. 역할 경계 확인하기

인턴은 감독 아래 준비 상태를 확인하고 식별·배치·측정 기록을 남긴다. 담당 엔지니어는 장비 운전, 시험 조건 승인, 안전 판정과 합격 판정을 맡는다. 측정 담당자는 정해진 측정 장비와 고정 측정점을 사용한다.

이상 상태를 발견하면 임의로 수정하거나 원인을 확정하지 않는다. 위치와 상태를 기록한 뒤 담당자에게 보고한다.

## 2. B 조건 체크리스트

1. 실행 ID와 캐리어 ID가 맞는지 확인한다.
2. 지정된 위치결정핀과 접촉면의 상태를 확인한다.
3. 캐리어 안착 확인점을 배치도와 대조한다.
4. 쿠폰 ID를 확인한다.
5. 쿠폰 좌표와 방향을 기록한다.
6. 고정 측정점 번호를 쿠폰 기록과 연결한다.
7. 준비 오류와 수정 내용을 남긴다.
8. 공구와 남은 쿠폰을 확인하고 준비 완료를 보고한다.

확보한 정보에 실제 장비 치수와 접촉 조건이 없어, 접촉식 위치 고정 장치를 추가하지 않는 비접촉 기록 방식으로 설계했다.

## 3. 기록 원칙

| 대상 | 함께 기록할 정보 |
|---|---|
| 캐리어 | 캐리어 ID, 안착 확인 상태, 확인자 |
| 쿠폰 | 쿠폰 ID, 좌표, 방향 |
| 실행 | 실행 ID, A 또는 B, 실제 순서, 블록 |
| 측정 | 측정기, 고정 측정점, 단위, 측정자 |
| 오류 | 오류 유형, 발견 단계, 수정 여부, 제외 사유 |

빈 값은 0이나 정상으로 바꾸지 않는다. 기록을 수정하면 원래 오류가 있었음을 남긴다. 같은 측정점을 반복 측정하면 같은 쌍과 측정점에 별도 `record_id`로 행을 추가하고 `notes`에 반복 회차를 적는다. 중단하거나 제외한 실행은 행을 지우지 않고 `notes`에 사유를 적으며, 필수값이 비어 있으면 유효 기록 집계에서 빠진다.

## 4. 비교 결과 읽기

준비 오류 감소와 고정점 두께 범위는 서로 다른 결과다. 체크리스트에서 준비 오류가 줄어도 두께 범위가 반드시 좁아지는 것은 아니다. 두께 범위에 차이가 있으면 AB와 BA 순서, 블록과 측정 반복성을 먼저 확인한다.

구체적인 분석 기준은 [캐리어·쿠폰 체크리스트 비교설계](comparison_plan.md)를 따른다.

CSV 검증 도구는 같은 실행의 오류 건수가 측정점마다 반복 기록돼도 실행당 한 번만 집계한다. 같은 측정점의 반복 측정은 별도 검토 대상으로 남기며, 첫 측정과 합쳐 두께 범위를 계산하지 않는다. 도구는 입력 형식을 검사하며 기록의 진위나 장비 안전성을 판정하지 않는다.

## 5. 이해 확인

- 캐리어 ID와 실행 ID를 어디서 대조하는가?
- 쿠폰 ID, 좌표와 방향을 모두 기록했는가?
- 준비 오류를 수정한 뒤에도 오류 이력을 남겼는가?
- A와 B의 실제 실행 순서와 블록을 기록했는가?
- 두께 차이와 측정 반복성을 구분했는가?
- 장비 운전과 최종 판정의 담당자가 누구인지 알고 있는가?
