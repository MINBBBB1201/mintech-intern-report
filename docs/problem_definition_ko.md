# 인턴 경험 기반 캐리어·쿠폰 준비 문제정의

한 달 동안 민테크 제조기술 부서에서 OLED 증착장비 제조 지원 업무를 수행했다. 인턴십 이후에는 이 경험을 바탕으로 캐리어 안착과 쿠폰 배치 정보를 비교 가능한 형식으로 기록하는 문제를 정의하고, 비접촉 체크리스트와 짝지은 비교설계로 발전시켰다.

## 1. 현장 역할

인턴십 초반에는 공장 현장 업무를 보조했고, 이후 사수를 따라 실무에 참여하며 지시받은 작업을 수행했다. 장비 운전, 시험 조건 승인과 합격 판정은 담당 엔지니어가 맡았다. 인턴 경험 설명에 따른 담당업무는 OLED 증착장비 제조 지원이다.

인턴십 뒤에는 이 경험을 공개 포트폴리오로 정리하면서 비교 항목과 데이터 구조를 구체화했다. 현장 업무와 후속 분석은 수행 시점을 나눠 설명한다.

## 2. 포트폴리오 문제 설정

인턴 경험을 정리한 뒤 OLED 증착장비의 일반적인 준비, 실행, 측정 흐름을 검토했다. 캐리어와 쿠폰의 식별 정보, 배치와 측정 조건을 연결하는 기록 문제를 후속 설계 과제로 선택했다. 회사의 실제 오류 사례나 당시 사용한 양식을 재현한 자료는 아니다.

## 3. 개선 과제로 정리한 항목

준비 상태와 측정값을 비교할 수 있도록 다음 항목을 같은 실행 ID로 연결한다.

- 캐리어 ID와 실행 ID의 연결
- 위치결정핀과 접촉면의 육안 확인
- 캐리어 안착 확인점
- 쿠폰 ID, 좌표와 방향
- 고정 측정점 번호

한 항목의 누락을 곧바로 두께 차이의 원인으로 볼 수는 없다. 준비 오류, 공정의 시간 경과, 실행 순서, 장비 상태와 측정 반복성이 함께 영향을 줄 수 있기 때문이다.

## 4. 설계안 검토

후속 설계에서는 접촉식 스토퍼와 비접촉 기록 방식을 비교했다. 실제 장비 치수와 접촉 허용 조건을 확인하지 못한 상태에서 부품을 추가하면 오염과 장착 간섭을 검토해야 한다. 장비를 변경하지 않고 준비 정보를 연결하는 비접촉 기록 방식을 설계했다. 이 비교는 문서상 대안 검토이며 현장 제안이나 시제품 시험 이력이 아니다.

수정안은 캐리어에 새 부품을 접촉시키지 않는 배치도와 체크리스트다. 캐리어 ID와 안착 확인점, 쿠폰 ID·좌표·방향, 고정 측정점을 한 실행 ID로 연결한다.

## 5. 비교 가능한 기록

기존 준비 방식 A와 체크리스트 준비 방식 B를 같은 조건에서 짝지어 비교한다. 핵심 결과는 준비 오류와 고정점 두께 범위다.

| 구분 | 기록 항목 | 해석 목적 |
|---|---|---|
| 식별 | 실행 ID, 캐리어 ID, 쿠폰 ID | 기록 연결 오류 확인 |
| 배치 | 쿠폰 좌표와 방향, 안착 확인 | 준비 오류 확인 |
| 조건 | 작업자 역할, 장비, 쿠폰 규격, 승인 조건 | A와 B의 비교 가능성 확인 |
| 순서 | AB 또는 BA, 실제 실행 순서 | 순서 효과 확인 |
| 블록 | 날짜, 장비 상태, 작업 구간 | 시간 경과와 블록 효과 분리 |
| 측정 | 고정 측정점별 두께, 반복 측정 | 두께 범위와 측정 반복성 확인 |

구체적인 비교 절차는 [캐리어·쿠폰 체크리스트 비교설계](comparison_plan.md)에 정리했다. 입력 파일은 [캐리어·쿠폰 기록시트](../templates/field_records.csv)와 [캐리어·쿠폰 비교분석 워크북](../workbooks/carrier_coupon_comparison.xlsx)이다.

## 6. 현재 결과

현재 결과는 준비 조건을 기록하고, 준비 오류와 공정 및 측정 변동을 구분해 검토하는 비교 구조다. 체크리스트의 성막 품질 개선 효과는 아직 측정하지 않았다.

이 기록 구조가 실제로 입력 누락과 조건 불일치를 구분하는지는 [기록 검증 결과](software_validation.md)의 소프트웨어 시험으로 확인했다. 시험 입력은 현장 효과를 추정하는 자료에 포함하지 않았다.
