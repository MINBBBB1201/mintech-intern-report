# 캐리어·쿠폰 체크리스트 짝지은 비교설계

기존 준비 방식 A와 비접촉 체크리스트 준비 방식 B를 비교하도록 설계했다. 준비 오류와 고정점 두께 범위를 각각 기록하고, 실행 순서와 블록 효과, 측정 반복성을 따로 검토한다. 현장 측정 전 설계이므로 수치 결과는 없다.

## 1. 비교 질문

체크리스트 방식 B는 기존 방식 A보다 캐리어와 witness coupon 준비 오류를 줄이는가? 같은 조건에서 얻은 고정점 두께 범위는 두 방식에서 어떤 차이를 보이는가?

인턴 이후의 문서상 대안 검토에서 접촉식 스토퍼와 비접촉 기록 방식을 비교했다. 실제 장비에 부품을 추가하기 위한 치수와 접촉 조건이 없으므로 이번 설계는 비접촉 기록 방식 B로 범위를 정했다. B는 새 부품을 추가하지 않고 식별, 안착, 배치와 측정 정보를 한 장에 연결한다.

![캐리어 안착 및 witness coupon 개념 배치도](carrier_layout.svg)

배치도는 기록 항목의 관계를 보여 주는 개념도다. 실제 원점, 쿠폰 수, 측정점과 접촉 금지 부위는 승인된 도면과 작업 절차를 기준으로 정한다.

## 2. 비교 조건

### A: 기존 준비

작업자가 기존 절차와 기존 기록 방식에 따라 캐리어와 쿠폰을 준비한다. 추가 체크리스트는 사용하지 않는다. 실제로 확인한 항목과 누락된 항목을 관찰 기록에 남긴다.

### B: 체크리스트 준비

작업자가 다음 항목을 순서대로 확인한다.

1. 실행 ID와 캐리어 ID를 대조한다.
2. 지정된 위치결정핀과 접촉면을 육안으로 확인한다.
3. 캐리어 안착 확인점을 배치도와 대조한다.
4. 쿠폰 ID, 좌표와 방향을 기록한다.
5. 쿠폰 배치와 고정 측정점 번호를 연결한다.
6. 준비 오류와 수정 내용을 기록하고 완료 상태를 보고한다.

## 3. 입력과 통제 조건

| 구분 | 입력 또는 통제 항목 |
|---|---|
| 식별 | 쌍 ID, 실행 ID, 캐리어 ID, 쿠폰 ID |
| 배치 | 쿠폰 좌표, 방향, 안착 확인 상태 |
| 시험 | 승인된 시험 조건, 쿠폰 규격, 장비와 측정기 |
| 순서 | AB 또는 BA, 실제 실행 순서 |
| 블록 | 날짜, 작업 구간, 장비 또는 챔버 상태 구분 |
| 결과 | 준비 오류 유형, 고정점별 두께, 제외 사유 |
| 반복성 | 같은 쿠폰 또는 기준 시편의 반복 측정값 |

A와 B는 가능한 범위에서 같은 쿠폰 규격, 측정 장비, 고정 측정점과 승인된 시험 조건을 사용한다. 조건이 달라지면 같은 쌍으로 묶지 않고 별도 블록으로 기록한다.

## 4. 역할

현장 시험을 실행할 경우의 역할을 다음과 같이 계획했다. 인턴 당시 수행한 시험은 아니다.

| 역할 | 담당 범위 |
|---|---|
| 인턴 | 체크리스트 초안, 감독하 캐리어·쿠폰 준비, ID·배치·측정값 기록 |
| 사수 또는 멘토 | 접촉 금지 부위, 준비 절차, 중단 조건 검토와 작업 감독 |
| 담당 엔지니어 | 시험 조건 승인, 장비 운전, 실행 제외와 결과 해석 결정 |
| 측정 담당자 | 정해진 장비와 고정 측정점으로 두께 측정, 반복 측정 수행 |

한 사람이 여러 역할을 맡으면 실행 기록에 실제 담당자를 남긴다.

## 5. 배정과 실행

A와 B를 한 쌍으로 배치하고 AB와 BA 순서를 번갈아 사용한다. 실제 실행 순서가 계획과 달라지면 계획값을 덮어쓰지 않고 변경 사유를 남긴다. 날짜나 장비 상태가 달라지는 지점에서는 블록을 나눈다.

준비 오류를 발견해 수정한 경우 오류를 삭제하지 않는다. 오류 유형, 발견 단계와 수정 여부를 함께 기록한다. 중단하거나 제외한 실행도 실행 ID와 사유를 보존한다.

## 6. 분석

### 준비 오류

조건별로 유효 실행 수와 준비 오류가 발생한 실행 수를 집계한다. 오류는 캐리어 ID 불일치, 안착 확인 누락, 쿠폰 ID 오류, 좌표 오류와 방향 오류로 나눈다. 표본이 작으면 비율만으로 일반화하지 않고 실행별 기록을 함께 읽는다.

### 고정점 두께 범위

각 실행에서 같은 고정 측정점의 `최댓값 - 최솟값`을 두께 범위로 계산한다. A와 B의 범위를 쌍별로 나란히 놓고 차이의 방향과 분포를 본다. 범위가 좁아도 성막 공정이 개선됐다고 바로 결론 내리지 않는다.

### 순서와 블록 효과

AB와 BA를 나눠 차이의 방향이 같은지 확인한다. 실행 순서나 블록에 따라 두께 범위가 함께 변하면 시간 경과에 따른 장비·챔버 상태가 섞였을 가능성을 검토한다. 블록 간 차이를 체크리스트 효과로 합치지 않는다.

### 측정 반복성

측정 담당자가 같은 대상과 고정 측정점을 반복 측정한다. 반복 측정의 차이가 A와 B의 차이와 비슷하거나 더 크면 준비 방식의 효과를 판정하지 않는다. 먼저 측정 절차와 장비 상태를 확인한다.

## 7. 정성 해석

B에서 ID·좌표·방향 오류가 줄어들면 체크리스트가 준비 누락을 줄일 가능성이 있다고 해석한다. 고정점 두께 범위까지 좁아져도 순서·블록 효과와 측정 반복성이 남아 있으면 원인을 캐리어 준비로 확정하지 않는다. A와 B의 차이가 없으면 체크리스트 항목이 실제 오류 지점과 맞는지 다시 검토한다.

현재 문서는 현장 측정 결과가 없는 비교설계다. 개선율이나 검정 결과는 제시하지 않는다. 실제 시험에서는 분석 방법과 판정 기준을 측정 전에 정하고, 결과를 본 뒤 유리한 기준으로 바꾸지 않는다.

기록 형식과 쌍의 비교 가능성은 별도 Python 도구로 검사한다. 실행 조건, 고정점 집합, 반복 측정 여부를 확인하며 조건이 맞지 않는 쌍의 두께 범위 차이를 계산하지 않는다. 이는 현장 A/B 효과 시험과 구분되는 [소프트웨어 검증](software_validation.md)이다.

## 8. 다음 검증

1. 측정 담당자가 반복 측정으로 측정 변동을 먼저 확인한다.
2. AB와 BA를 균형 있게 배치하고 블록별 실행 수를 확보한다.
3. 준비 오류 유형별로 체크리스트 문항의 탐지 여부를 확인한다.
4. 순서·블록 효과를 분리한 뒤 A와 B의 고정점 두께 범위를 비교한다.
5. 담당 엔지니어가 안전·오염 조건과 현장 적용 여부를 검토한다.
